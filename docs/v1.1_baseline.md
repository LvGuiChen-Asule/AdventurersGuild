## 2. 当前架构（V1.0）

### 2.1 包职责

| 包 | 关键类 | 职责 |
| --- | --- | --- |
| `quest` | Quest / QuestType / QuestQuality / QuestStatus / QuestProgress / QuestPoolEntry / QuestChain / **QuestManager(638 行)** | 任务领域模型 + 全部服务端权威逻辑（6 种类型 / 品质倍率 / 门槛 / 精英怪 / 商店购买 / 刷新） |
| `player` | **AdventurerData(296 行)** / AdventurerCapability / LevelData / ReputationData | 玩家数据能力 + NBT 持久化 + 等级/声望曲线 |
| `data` | QuestRegistry / QuestPoolRegistry / QuestChainRegistry / ShopRegistry / EquipmentRegistry / GuildDataLoader / **DailyBoardManager** | JSON 数据加载（数据包重载）+ 每日任务板（World SavedData） |
| `economy` | Shop / ShopItem | 商店数据 |
| `equipment` | EquipmentData / EquipmentEffects | 饰品效果 + Curios 反射软集成 |
| `npc` | GuildNpcHandler | 标记村民 NPC（非真实实体） |
| `registry` | AGRegistry / GuildTerminalBlock | 物品/方块/创造标签注册 |
| `network` | GuildNetwork / GuildDataPacket + 5 个 C2S | 通道 + 数据快照 + 请求包 |
| `command` | AGCommands | `/ag` 命令（16 个子命令） |
| `client` | AbstractGuildScreen + 6 个界面 + ClientPacketHandlers | UI 渲染与客户端包处理 |

### 2.2 核心数据流

```
Client(显示/请求) → C2S 包 → QuestManager(服务端校验) → AdventurerData(NBT 能力)
                                              ↓
                          GuildDataPacket(S2C 快照) → ClientGuildData → Screen
```

- 服务器权威：接受/进度/完成/发奖/购买/刷新全部在 `QuestManager`，客户端只发请求
- 数据驱动：任务/池/链/商店/装备均来自 `data/adventurersguild/*/*.json`，数据包重载时刷新
- 持久化：玩家数据=能力 NBT（随存档）；每日任务板=`GuildDailyData`（SavedData）

### 2.3 玩家数据结构（AdventurerData NBT 字段）

`registered / level / experience / gold / reputation / activeQuests / completedQuestCount / abandonedQuestCount / completedQuestIds / dailyRefreshCount / lastRefreshDay / chainProgress`

### 2.4 网络协议（V1.0）

| ID | 包 | 方向 | 用途 |
| --- | --- | --- | --- |
| 0 | GuildDataPacket | S2C | 全量快照（任务/每日板/链/商店/玩家状态）+ 打开/刷新界面 |
| 1 | AcceptQuestPacket | C2S | 接任务 |
| 2 | AbandonQuestPacket | C2S | 放弃 |
| 3 | RegisterAdventurerPacket | C2S | 注册 |
| 4 | BuyItemPacket | C2S | 商店购买 |
| 5 | RefreshBoardPacket | C2S | 刷新任务板 |

## 3. 当前功能清单（V1.0 完整）

1. 任务系统：32 个数据驱动任务、6 种类型（COLLECT/HUNT/EXPLORE/SURVIVE/TRANSPORT/ELITE）
2. 任务品质：COMMON 1.0 / UNCOMMON 1.25 / RARE 2.0 / EPIC 3.0 / LEGENDARY 5.0
3. 每日任务板：每天 3 普通 + 2 优秀 + 1 稀有；免费刷新 3 次/天，之后 50/100/150/200 金币
4. 成长：Lv1–Lv6（0/300/900/2000/4000/7500）+ 6 个等级称号
5. 声望：6 阶段（0/100/300/800/1500/3000）+ 任务/商店/链门槛
6. 经济：3 个商店（Lv1 补给 / Lv3 高级 / Lv5 特殊），金币购买、等级解锁、背包溢出掉落
7. 装备：5 件饰品（EXP/金币/挖掘/敌对伤害/移速 +5%），Curios 反射软集成 + 无 Curios 手持兜底
8. NPC：接待员/任务管理员/商店管理员（`/ag spawnnpc`，标记村民实现）
9. 公会世界入口：公会终端方块（右键开大厅）+ 创造标签
10. 任务链：3 条（矿工之路/夜色猎手/公会试炼），前置解锁、完成自动推进
11. 新手引导：Tutorial_001 置顶，完成后解锁正式大厅
12. UI：任务大厅/详情/我的任务/冒险者信息/商店/任务链（6 界面，中英双语）
13. 命令：`/ag` 16 个子命令（含开发命令，OP2）
14. 持久化：玩家能力 NBT + 每日板 SavedData；死亡克隆保留数据
