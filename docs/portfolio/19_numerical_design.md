# 19 数值策划

## 数值设计原则

1. **奖励 = 基础值 × 品质倍率 × 装备加成**：单一公式贯穿任务/每日板/商店，改一处全联动；
2. **小数值起步**：饰品一律 +5%，品质倍率从 1.0 到 5.0 递增，不做"一刀 999"；
3. **双门槛**：等级管"能力"，声望管"身份"，两个维度互相独立，避免单曲线瓶颈；
4. **所有货币有源有汇**：金币有产出（任务）就必须有回收（刷新/商店）；
5. **观察优先于调参**：V1.1 先埋观察指标，V1.2 依据真实数据调参（不拍脑袋改数值）。

## 金币经济（V1.0 已实现）

| 项目 | 数值 |
| --- | --- |
| 每日板金币产出 | ≈511 G/天（上限口径） |
| 刷新成本 | 免费 3 次/天 → 50/100/150/200 G（封顶 200） |
| 补给店 | 5–12 G（火把/箭/面包/木板） |
| 装备店（Lv3） | 40–150 G（铁装/金苹果/蜂蜜） |
| 特殊店（Lv5） | 200–600 G（钻石装/末影珍珠/金苹果） |
| 金币上限 | 1,000,000,000（防溢出） |

设计意图：每日板产出 ≈ 512G，全买刷新（2 次 150G）+ 补给（≈50G）后仍有结余，
但钻石装 600G 需要 2–3 天积累 → **短期盈余、长期稀缺**，避免通胀也避免无目标。

## V1.1 观察指标（已埋点，V1.2 调参依据）

| 指标 | 关注点 |
| --- | --- |
| 每日板完成率 | 任务难度/时间是否匹配（目标 >60%） |
| 刷新使用率与付费刷新次数 | 金币回收效率（目标 1–2 次/人/天） |
| Lv2/Lv4/Lv6 达成天数 | 成长曲线是否平滑 |
| 声望 Tier3 达成率 | 任务链门槛 800 是否过高 |
| 商店商品购买分布 | 定价与需求错配 |
| 任务放弃率（abandoned） | 超时/目标设置是否合理 |

## VALUE：体现什么策划能力？

- **数值推导**：所有估算都有公式与假设，可复现、可调参；
- **经济学思维**：产出/回收/封顶/通胀全链路设计；
- **数据驱动**：先埋指标再调参，而不是拍脑袋；
- **诚实口径**：升级时间明确标注"下限口径+假设"，不吹嘘。
