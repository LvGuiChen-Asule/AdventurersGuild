# 15 饰品 / 遗物系统

## WHY：为什么需要饰品？

V1.0 的任务奖励只有金币/EXP/声望三种"货币"，玩家成长感受不到**玩法变化**。
饰品是第一个"非货币成长"：让不同任务偏好（采集/狩猎/探索/刷金）有对应的**装备侧反馈**，
也验证了"Curios 软集成"这条技术路线——不装 Curios 也能玩，装了就有装备栏。

## WHAT：5 件饰品（V1.0 已实现）

| ID | 名称 | 槽位 | 效果 | 数值 |
| --- | --- | --- | --- | --- |
| adventurer_badge | 冒险者徽章 | charm | 任务 EXP 奖励 | +5% |
| miner_ring | 矿工戒指 | ring | 挖掘速度 | +5% |
| hunter_badge | 猎人徽章 | charm | 对敌对生物伤害 | +5% |
| explorer_charm | 探索护符 | charm | 移动速度 | +5% |
| guild_badge | 公会徽章 | charm | 任务金币奖励 | +5% |

> 数据现状：equipment JSON 含 id/item/slot/effect/value/description_key；**没有品质字段**，
> 品质与正式获取途径属于 V1.2 规划。当前获取方式为创造标签（与公会终端同组），
> 生存模式通过手持/Curios 装备验证效果（无配方、无掉落——已在审计中如实标注）。

### 每件饰品的玩法定位（不是"+5% 属性"）

| 饰品 | 玩法定位 | 鼓励的玩家行为 | 设计目的 |
| --- | --- | --- | --- |
| 冒险者徽章 | 任务成长流 | 多接任务、完成每日板 | 让"任务党"有成长加速感 |
| 矿工戒指 | 资源采集流 | 挖矿、下矿洞、补货任务 | 让采集类任务更顺滑 |
| 猎人徽章 | 战斗流 | 夜间狩猎、精英讨伐 | 让 HUNT/ELITE 玩家有战斗正反馈 |
| 探索护符 | 旅行流 | 跑图、探索群系、远征 | 移动速度=探索时间成本下降 |
| 公会徽章 | 经济流 | 刷金币、买商店、刷新板 | 金币流玩家的"印钞机"（受数值上限约束） |

### 平衡风险与约束

- 全部为 **5% 小数值**：单件不改变玩法节奏，避免"数值膨胀压过原版"；
- 同效果可叠加求和，但来源只有 5 件，叠加上限低（任务 EXP 最多 +5%）；
- EXP/金币加成只作用于**任务奖励**，不作用于击杀/采集原版掉落 → 不会破坏原版经济；
- 挖掘/移速/敌对伤害是原版属性修饰（MULTIPLY_TOTAL），数值极小，风险可控。

## HOW：玩家怎么使用？

1. 创造标签获取饰品（V1.0 现状）→ V1.2 计划改为商店购买/精英掉落/任务奖励；
2. 装了 Curios：放入对应槽位（charm/ring）生效；
3. 未装 Curios：主手/副手持有即生效（演示兜底，保证核心循环可用）；
4. 移速效果由服务端每帧/每 tick 应用属性修饰符，其他效果在发奖/造成伤害时查询总和。

## DATA：数据结构（V1.0 已实现）

```json
{
  "id": "adventurer_badge",
  "item": "adventurersguild:adventurer_badge",
  "slot": "charm",
  "effect": "quest_exp",
  "value": 0.05,
  "description": "equipment.adventurersguild.adventurer_badge.desc"
}
```

与任务系统的关系：`实际奖励 = 基础值 × 品质倍率 × (1 + 饰品加成)`。

## IMPLEMENT：怎么落地？

- `registry/AGRegistry`：5 个 Item + 创造标签注册；
- `data/EquipmentRegistry`：JSON 加载；
- `equipment/EquipmentEffects`：Curios 反射软集成 + 手持兜底；
- 效果挂接点：任务发奖（EXP/金币）、伤害事件（敌对伤害）、属性修饰（移速）、挖掘速度（采集判定）。

## 与主线 / Endgame 的关系

- 主线：饰品是"成长准备"的一环——远征下界/末地前换装备是冒险感的一部分（V1.2 规划任务链奖励）；
- Endgame：V1.1 遗物系统扩展方向（见下），让"龙之后"有装备追求。

## V1.1 遗物系统扩展方向（规划，未实现）

原则：**遗物应该改变玩法，而不是堆属性**。

| 构想 | 效果类型 | 目标行为 |
| --- | --- | --- |
| 传送卷轴遗物 | 功能型 | 野外快速回公会（改变补给节奏） |
| 龙息容器 | 战斗型 | 击杀 BOSS 计数/强化精英讨伐 |
| 探险家日志 | 探索型 | 显示群系/遗迹方向（探索辅助） |
| 旧时代徽章 | 世界观型 | 解锁隐藏对话/档案分支 |
| 折跃核心 | Endgame 型 | 末地外岛折跃门加速/定位 |

> 以上均为 V1.2/V2.0 概念规划，未写入代码；写在这里是为了展示"从数值到玩法"的设计思路。

## VALUE：体现什么策划能力？

- **数值策划**：5% 小数值 + 加成公式 + 叠加约束的完整推导；
- **系统设计**：饰品与任务类型（COLLECT/HUNT/EXPLORE）一一对应，形成"行为-奖励"闭环；
- **工程沟通**：软依赖设计（Curios 反射 + 兜底）让"没有前置 Mod 也能玩"成为卖点；
- **诚实标注**：创造标签获取、无品质字段等现状如实记录，不把规划写成实现。
