# 04 世界结构与公会建筑

## 世界结构

```mermaid
flowchart LR
    subgraph 主世界
        A[公会大厅] --> B[出生点周边]
        B --> C[平原/森林/沙漠等生物群系]
    end
    C --> D[下界]
    D --> E[下界堡垒]
    E --> F[末影之眼/要塞]
    F --> G[末地]
    G --> H[末影龙]
```

设计原则：**不改变原版世界结构**。公会作为"枢纽"嵌入主世界，下界/末地保持原版流程，Mod 只在关键节点"记录与回应"。

## 公会建筑（V1.1 已实现，程序生成）

- 规模：45×35 占地、约 20 格高，原版材质（橡木/石砖/石英/金块）
- 地表确定性放置：出生点附近搜索合规地表 → 铺模板 → 清平周边 4 格地形
- 功能分区：主大厅 / 接待台（石英柜台+办公室）/ 任务墙（羊毛马赛克）/ 徽章墙（金块）/ 商店（石英柜台）/ 档案室（书架）/ 远征室 / 地图室 / 休息区（床）/ 仓库（木桶）/ 6 个 NPC 站位地毯
- 照明：萤石 ×13 + 吊灯，防刷怪

## 玩家动线

```
大门 → 接待台（注册）→ 任务墙（接任务）→ 远征室（问路线）
→ 商店（补给）→ 档案室（看记录）→ 休息区/仓库 → 出发冒险
```

## 为什么"实体建筑"而不是纯 GUI？

1. **可发现性**：玩家通过探索找到公会，本身就是一次"世界反馈"
2. **空间记忆**：地图上的地标比菜单入口更有叙事重量
3. **动线即教程**：进门顺序天然引导注册→任务→补给
4. **作品集说服力**：展示"策划的平面功能图落地成真实世界建筑"

## 生成规则（V1.1 已实现）

- 每世界恰好一个主公会（记录于 GuildWorldData）
- 位置：出生点 96 格内优先"允许生物群系"（平原/森林/草甸/针叶林等），陆地兜底
- 放置前清理占地内高于地表的地形 + 四周 4 格空档（泥土台地）
- NPC 由建筑内彩色地毯定位生成（旋转/高度安全）
