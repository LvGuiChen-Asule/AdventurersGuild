## 每镜技术要点

### 镜头 1（项目介绍）

- A 档：`/ag guild locate` 确认坐标，飞到公会高空慢推；
- 标题卡用剪辑软件叠加："ADVENTURER'S GUILD — AI Vibe Coding × Game Design"。

### 镜头 2（进入公会）

- 录真实走路进门，不瞬移；
- 展示入口橡木门（补门修复的成果）与大厅萤石。

### 镜头 3（NPC / 任务）

- 右键艾琳 → 选"注册冒险者" → 打开任务大厅（J 键）；
- 强调任务列表品质色（蓝=RARE）。

### 镜头 4（执行任务）

- 接 `hunt_witches`；传送/飞行到沼泽（剪辑可加速）；
- 击杀 3 只女巫，剪辑到 40 秒内。

### 镜头 5–6（完成与成长）

- 完成提示（金币/EXP/声望）→ 打开冒险者信息（K 键）；
- 若 Lv 变化不明显，可先用 `/ag addexp` 使升级发生在镜头内（开发命令，OP2，剪辑可隐藏）。

### 镜头 7（第二成长线）

- 打开档案（K 键 Chronicle）：事件列表 + Lore + 拜访计数；
- 饰品界面：展示 5 件 + 效果（冒险者徽章等）。

### 镜头 8（AI 开发流程）

- 用 Codex 会话截图（Prompt→Code Change）——**必须真实截图，禁止伪造**；
- 4 张迭代卡：地下 Y=0 → 地表；门掉落 → 补门；NPC 房顶 → 地毯定位；地形穿模 → 清空+空档。
