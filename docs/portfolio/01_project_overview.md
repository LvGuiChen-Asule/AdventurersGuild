# 01 项目概述

## WHY：为什么做这个项目？

Minecraft 原版的核心矛盾：**自由度极高，但缺少持续的任务驱动与世界反馈**。玩家不缺"能做什么"，缺的是"为什么做、做完会怎样"。

Adventurer's Guild 不改变 Minecraft 的核心玩法，而是给原版本来就存在的行为（采集、狩猎、探索、进下界、进末地、打龙）**赋予目标、奖励与叙事意义**。

## WHAT：是什么？

Minecraft 1.20.1 Forge 的"任务驱动型冒险成长系统 Mod"：

```
发现公会 → 注册冒险者 → 接取任务 → 准备冒险 → 探索世界
→ 完成任务 → 获得 EXP/Gold/Reputation → 成长 → 解锁更高内容
→ 推进主线（主世界 → 下界 → 末地）→ 击败末影龙 → Endgame
```

V1.1 定位升级：**以原版主世界→下界→末地为冒险主线，以冒险者公会为世界枢纽**。

## HOW：怎么玩？

1. 玩家在原版世界里自然发现公会大厅（地表建筑，非纯 GUI）
2. 注册成为冒险者，从任务墙接取任务
3. 任务驱动玩家去做原版行为（采集/狩猎/探索/生存/运输/讨伐）
4. 世界持续记录玩家行为（事件/档案），NPC 与对话随之变化
5. 击败末影龙解锁 Endgame，冒险继续

## DATA：怎么量化？

- 80 个数据驱动任务、5 品质、6 类型（支线）+ 3 类型（主线/成就）
- 6 级成长曲线、6 阶段声望、3 商店、5 饰品、3 任务链
- 15 世界事件、12 Lore、24 Endgame 目标

## IMPLEMENT：怎么落地？

- 任务/商店/装备/对话/章节/事件/Lore 全部 JSON 数据驱动，配表维护于 Excel
- 服务器权威：接受/进度/完成/发奖/购买全部服务端判定
- 持久化：玩家能力 NBT + 世界 SavedData

## VALUE：体现什么能力？

系统策划（任务/成长/声望/经济闭环）、任务策划（主线/支线/任务链）、数值策划（EXP/Gold/Reputation 曲线）、数据驱动（JSON+Excel）、UI/UX（10 界面）、程序落地（Forge 全栈）。

## 项目定位声明

本项目主要用于展示：游戏系统策划、任务设计、数值设计、UI/UX 设计与 Minecraft Mod 工程实现能力。
